Mono badge carrying a node's type mark + label — use on every tree card, outline row, and the editor panel header.

```jsx
<NodeBadge kind="monstre" label="FIN · VICTOIRE" selected />
```

Marks: filled square (sommaire), outline square (choix), circle (pnj), dashed square (decor), triangle (piege), hatch (monstre), double border (fin), gray hatch (mort). `selected` switches the mark + border to accent.
